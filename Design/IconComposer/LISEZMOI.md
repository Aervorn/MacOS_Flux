# Calques pour Icon Composer

Calques de l'icône de Flux pour Icon Composer (macOS 26), tirés de `../make_icon.py`.
Tous sur le même canevas de 1024 × 1024, à pleine taille : ils se superposent sans réglage.

| Fichier | Contenu | Réglage dans Icon Composer |
|---|---|---|
| `1-fond.svg` | Dégradé orange → rose, plein cadre | Calque du fond (ou couleur de fond : #FFB054 → #E8336B) |
| `2-ondes.svg` | Point et deux premières ondes, blancs | Opacité 100 % |
| `3-onde-pale.svg` | Troisième onde, blanche | Opacité 38 % (l'onde qui s'estompe) |

Pas de coins arrondis, d'ombre ni de reflet : macOS les ajoute lui-même.
